WHAT THIS IS
 A complete TunerPro definition for the stock 5JCZSJ10 read, built from the SD-v5 knowledge base
 with every speed-density / anti-lag item removed or restored to its stock definition. Fueling is
 Suzuki's own IAP(vacuum) x TPS blended strategy, untouched. No code patches. Bin is not modified.

HOW THE STOCK FUEL STRATEGY WORKS (what to tune, in order)
 base fuel = IAP_map x (256 - w) + TPS_map x w            (FUN_453B8 / FUN_491BC)
  - w = 0 below "Fuel Blend - MAP->Throttle Threshold (vs RPM)" (stock 15.0 deg @1200 rpm .. 38.2 deg
    @10800 rpm), ramps to 256 over 16<<6 counts = 2.8 deg ("Fuel Blend :: MAP->Throttle Ramp Width"),
    forced to 256 at/above the WOT gate (91.4 deg, held 4 cycles after you drop below it).
  - So: idle / cruise / part throttle = "IAP - In Gear | Cyl 1-4" (vacuum x rpm);
        bigger openings and WOT = "TPS - In Gear | Cyl 1-4" (throttle x rpm).
  - Neutral or clutch pulled (after 3 cycles, vacuum >= 0 kPa) = the Neutral/Clutch-In IAP/TPS maps.
  - Sensor fault limp-home forces w = 256 (TPS maps).
 Then corrections multiply in (FUN_45C18): ECT warm-up, afterstart (3 stages), IAT density, baro,
 per-gear enrichment (TP >= 77.3 deg), accel enrichment, HO2 closed loop + adaptive trims, decel cut.
 Injector time = deadtime(Vbatt) + fuel x (K-400)/200, clamped 250..25000 us.

 Starter relay engage < 500 rpm, drop-out 1000 rpm.

DIAGNOSTICS
 - "Diagnostics - Monitor Enables (DTC on/off)": one flag per enable byte (0x80 = monitor runs).
   Unticking stops the monitor itself (no code, no lamp, no fail-safe for that fault). 10L1 already ships
   with EVAP, oil temp/pressure, PAIR system, fuel-system (lean/rich), several range/performance and
   misfire monitors OFF. Safety monitors (APS/TPS, CKP/CMP, ECM, EEPROM, oil pressure, CAN) carry a warning.
 - "Diagnostics - DTC Lamp Control": lamp-only toggles (unchanged from v8/SD-v5).
 - "Diagnostics - Monitor Thresholds (per DTC)": the limits/debounce counts each monitor reads.
   For a race bike with the O2 sensors / PAIR / exhaust valve removed, switch those monitors OFF here
   rather than editing thresholds.

AUTO-DEFINED ITEMS - READ THIS
 Anything whose description says "AUTO-DEFINED" was generated from the code cross-reference: the address,
 width, signedness, reading function and the decompiled line that uses it are exact; the name and the
 inferred unit are best-effort (taken from the RAM variable it is compared with). Treat them as a map of
 what exists. Log before you change one, and change one thing at a time.

   Phase Fuel Factors (0x15431A-0x15432A). Shift Detection Options A/B (0x154452/53) left as "leave 0x80".

 - TOP SPEED: the ~299 km/h governor is "Per-Gear Limiter | 6th" (10,450 soft / 10,550 rpm hard, enabled by
